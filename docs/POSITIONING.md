# NetDive 项目定位与生态坐标白皮书 (Product Positioning & Ecosystem Matrix)

> **一句话定位**：面向本地 CLI AI Agent 的轻量级「因果沙盘与安全拦截」控制台 (A lightweight visual debugger & control plane for local AI Agents)。

---

## 1. 为什么手搓 NetDive？生态定位与差异坐标

在当前的 AI Agent 工业界，可观测性与交互工具主要呈现两个极端，而个人本地开发场景被完全忽视：

| 维度 | 云端 APM 平台 (如 Langfuse / Phoenix) | 桌面全家桶 (如 Dify / AutoGen Studio) | **NetDive (面向极客的本地控制台)** |
| :--- | :--- | :--- | :--- |
| **部署形态** | 依赖 Docker / 云端 / 远程数据库 | 巨型桌面 GUI / 全屏 Electron 软件 | **极轻量 本地 Web 副屏 (即起即用)** |
| **接入成本** | 业务代码必须强行安装 SDK 侵入打点 | 强制在软件内写 Prompt，绑架工作流 | **基于宿主账本/W3C Trace 零侵入监听** |
| **控制时机** | **事后日志记录**（出事后画折线图） | 软件内部预设流程，无法脱离 GUI | **事前/事中毫秒级拦截**（Promise 挂起） |
| **交互视野** | 表格、调用链树状瀑布流 | 聊天窗口 + 局部面板 | **DAG 因果拓扑图 + 参数热篡改沙盘** |

### 核心论点：
1. **不做事后记账器**：如果只是记录消耗了多少 Token 和时长，开源界已经有很多轮子。NetDive 探索的是**如何实时干预和阻断 Agent 的执行命运**；
2. **不绑架极客的终端习惯**：开发者依然在命令行（Pi / Hermes / Claude Code）里享受毫秒级敲击与纯文本沉浸感；NetDive 作为一个**外置的副屏雷达仪**，平时静默画图，关键时刻提供阻断拦截。

---

## 2. 为什么终端会话拦截不够用？（沙盘 vs 看门狗）

> **常见质疑**：*终端里直接问 `[y/N]` 也能拦截，特地做一个网页弹窗是不是多此一举？*

答案是：**在复杂的自主长链路 Agent 中，终端文字交互存在无法克服的物理极限**。

```text
终端拦截（看门狗模式）：
  [CLI 字符流滚动...] 
  -> Agent: "rm -rf ./cache/dist"
  -> Prompt: Confirm [y/N]? 
  ❌ 局部盲人：看不清前 15 步的上下文与因果动机
  ❌ 死板二选一：无法修改参数，按 N 直接挂死

NetDive（因果沙盘控制平面）：
  [DAG 拓扑流式展开...]
  -> 节点高亮红黄闪烁，清晰指向前置测试挂掉的因果连线
  ✅ 因果可视：秒级看清前因后果，消除误杀与心虚
  ✅ 富文本 Diff 审查：Monaco Editor 双列对比文件变更细节
  ✅ 参数热篡改：直接在节点输入框将错误参数修改后放行 (Hot Mutation)
```

### 三大物理极限突破：
1. **宏观因果视野 (Causal Horizon)**：
   终端是单向流动的滚动日志，当 Agent 在第 15 步执行危险操作时，人类处于“上下文失忆”状态。NetDive 用 DAG 图展示上游节点（思考、抓取、试错），一目了然看清意图；
2. **从“死板二选一”到“热参数注入 (Hot Param Injection)”**：
   终端只能选批准或拒绝。若 Agent 命令中的某个超时时间（如 5000ms）太短，终端拒绝会导致链路终止；而在 NetDive 中，用户可以直接就地修改为 30000ms 并点击“修改并放行”；
3. **沉浸式开发的心智解耦**：
   主屏幕全屏写代码，副屏 NetDive 作为静默雷达。高危动作发生时副屏亮灯审查，不需要打断主屏终端的输入环境。

---

## 3. 面向面试与对外展示的核心故事线

当面试官或同行问起 NetDive 时，回答的核心骨架：

> “**这个项目不是业务 Agent 本身，而是针对自主 Agent 不可控痛点的控制平面（Control Plane）**。
> 业界现有的 Langfuse 主要是事后 APM，解决不了 Agent 执行时的实时阻断；而桌面全家桶又太重，剥夺了命令行极客的自由。
> 我手搓 NetDive 重点攻坚了两个核心能力：
> 1. 利用 W3C Trace Context 实现了对本地 Agent 进程的零侵入拓扑嗅探；
> 2. 基于前端 Promise 挂起状态机，实现了集‘因果回溯、富文本 Diff 比对与参数热篡改’于一体的外置安全拦截控制台。”
